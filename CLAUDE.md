Skip duplicates, list anything unclear instead of guessing, show me a table of the added words, then commit and push to main.

### How to apply them
- The word file is **`site/data/sets.json`** ("data/sets.json" in the rules = this file; it lives inside `site/` because Vercel's Root Directory is `site`). It is the permanent storage.
- Set: `{ "id", "title", "dateCreated" (YYYY-MM-DD), "source" ("textbook" | "my"), "cards": [...] }`
- Card: `{ "id", "kanji", "kana", "ukrainian", "verbGroup", "hint", "section", "source" }`
  - `kanji` — word as written with kanji, `""` if the word has no kanji
  - `kana` — reading in kana (for kana-only words: the word itself). For my words with kanji, add the hiragana reading yourself.
  - `ukrainian` — meaning exactly as written
  - `verbGroup` — `"I"`, `"II"`, `"III"` or `""`
  - `hint` — usage hint in square brackets as written, e.g. `"[じかんに～]"`, else `""`
  - `section` — `"main"`, `"dialogue"` (◊ 会話 ◊), `"reading"` (読み物)
  - `source` — `"textbook"` or `"my"`
  - optional `"check": true` = word from OCR / auto-generated reading that I still need to check (shown with a «перевірити» badge)
- Ids: set ids are lowercase slugs (`mnn-01`, `my-…`); card ids `<setId>-<n>`; never reuse or renumber ids (browser progress is keyed by `setId/cardId`).
- Keep the file layout: one card per line (same format the save API writes). Validate before committing:
  `node -e "JSON.parse(require('fs').readFileSync('site/data/sets.json','utf8'))"`
- Duplicates = same kanji/kana with the same meaning already in the target set — skip and report them.
- Always show me a table of the added words, then `git commit` and `git push origin main`.

## AI helper «Запитай ШІ» (Exam + Grammar) — `site/js/ai-helper.js` (Puter.js, no key)

No API key, no server function, no env variable: each learner signs in to their own free Puter account (Puter's “user-pays” model with a free monthly allowance) on the first question. The site's `APP_PASSWORD` is not used by the helper (only by `/api/save-set`).
- The script is added only by pages with the helper (`loadPuter()` in `mountAskBlock`, with `defer`: exam pages and grammar lessons), never in `index.html`. Sign-in (`puter.auth.isSignedIn` / `signIn`) runs on the click on «Надіслати» so the popup is not blocked; cancelled/blocked → «Щоб отримати пояснення, увійдіть у безкоштовний акаунт Puter», the page keeps working.
- Model: `MODELS` in `ai-helper.js` = `claude-haiku-5-5` (cheapest strong model on Puter, 2026-11), fallback `gpt-5.4-nano` (Puter's default). Current list: `https://api.puter.com/puterai/chat/models/details` or `puter.ai.listModels()`. System prompt = `SYSTEM` in `ai-helper.js`, sent with every request. Errors → «Не вдалося отримати відповідь, спробуйте ще раз» (real error code/message in the console only).
- Exam UI: «Чому так? Запитати ШІ» after each answer and on each mistake in the results, «Запитай ШІ» block at the bottom of run, paper and results pages. It only reads the exam session and must never write to it. Last 5 messages: sessionStorage `jp.examAsk`. Limit 1000 characters of question + exam context.
- Grammar UI: the same block at the bottom of every lesson (`grammar.js`, before the pager), select «Про що запитання»: «Увесь урок» or one point (a `#/grammar/<l>/<pointId>` link preselects it). The material of the choice (`askTopics`: lesson, point title, textbook blocks with translations, «Детальніше»; furigana as 漢字(かな); caps 6000 / 9000 characters — every point/lesson fits) is appended to the system prompt (`MATERIAL_INTRO`), not counted in the 1000. History per lesson: sessionStorage `jp.ask.grammar.<n>`. Exam → grammar: a reference link saves the question's context in `jp.examReturn` (`{ at, lesson, ask }`, exam.js `wireRefs(root, askOf)`); the lesson's block shows it (exam prefill «Поясни, будь ласка…») while «Повернутися до екзамену» is active.
